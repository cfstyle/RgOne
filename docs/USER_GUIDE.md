# 行内大模型自助接入与案例门户 (RgOne Portal) 用户与管理员操作指南

## 一、 员工前台操作手册

### 1. 登录与身份认证（小秘书动态验证码统一入口）
1. **统一登录入口**：
   - 点击顶栏右侧「工号登录」胶囊按钮，打开统一身份核验窗口。
   - 输入您的 **8 位行内工号**（例如 `06700956` 或 `06701099`）。
   - 点击「获取验证码」，系统通过行内小秘书即时消息服务，将 6 位动态验证码定向推送至您名下的小秘书客户端（5 分钟内有效，60 秒发送冷却）。验证码不会在页面或日志中回传。
   - 发送成功后工号自动锁定，光标自动聚焦至验证码输入框。
   - 输入收到的 6 位验证码并点击「登录 / 接入平台」，系统自动验证并签发 7 天专属会话凭证，同时留在原业务位置无需强制跳页，顶栏展示当前身份（如 `陈飞 · 06700956`）。
   - *(注：若输入管理员账号 `admin`，系统将自动识别并切换为密码输入框，直接凭密码登录后台)*。

2. **登录与 Key 申领解耦（高可用保障）**：
   - 验证码通过即完成员工身份认证。首次登录系统在后台自动向算力网关申领专属 API Key；已有 Key 自动复用。
   - 若算力网关暂时故障或网络抖动，系统不阻断登录流程，员工正常进入系统，页面醒目提示「已登录，Key 暂未申领成功」。
   - 员工可在首页卡片或工作台直接点击「重新申领」，沿用当前会话凭证重新获取 Key，无需重新收发验证码。

### 2. 快速上手向导（三步极简接入）
1. **下载客户端**：
   - 访问门户首页「快速上手」，在第 1 步卡片点击「下载安装包」。若系统尚未上传安装包，卡片明确提示「暂无可下载安装包，请联系管理员上传」。
2. **获取与查看专属 API Key**：
   - 完成工号登录后，第 2 步卡片与「我的工作台」自动展示专属 API Key。
   - 默认以掩码方式展示（如 `sk-rgon...7673`），可点击眼睛图标切换显隐，或直接点击复制按钮（内置内网非 HTTPS 环境下的安全剪贴板降级机制）。
3. **配置 DeepSeek Harness 客户端**：
   - **方式一（界面粘贴配置·推荐）**：
     打开 DeepSeek Harness 客户端，点击左下角 `设置 -> 模型 -> 自定义模型 API`，依次点击门户页面上的「一键复制」按钮，将以下 5 个字段粘贴进去：
     - **Provider ID**: `new-api-1`
     - **显示名称**: `行内大模型平台`
     - **API 地址**: `http://30.20.4.144:3001/v1`
     - **API 协议**: `OpenAI Chat Completions`
     - **API 密钥**: 点击复制自己的专属 Key（`sk-...`）
     点击保存即可。后续网关新增模型时，只需在客户端「编辑 -> 刷新模型目录」即可实时生效，无需重复配 Key。
   - **方式二（配置文件补丁）**：
     点击下载动态生成的 `cordis.patch.yml`，点击客户端右上角「打开配置文件」，将下载的文件覆盖后重启客户端即可（默认已关闭遥测打点）。

### 3. 我的工作台与用量看板
* **查看与重置 Key**：在工作台顶部卡片可查看自己的 Key（默认掩码，支持显隐与复制）。若怀疑密钥泄露，可点击「重置 Key」，系统将向网关吊销旧凭据并生成新 Key，历史用量统计完全继承不断层。若该账号已被管理员停用，自主重置将被安全阻断（403）。
* **用量分析看板**：
  - 支持按「今日 / 近 7 天 / 近 30 天 / 全部」切换统计周期。
  - 查看 Token 消耗总览（Prompt 输入 / Completion 输出拆解）、请求频次与最常用模型。
  - 查看调用明细列表与实时响应耗时。
  - 界面实时展示「数据更新至：YYYY-MM-DD HH:mm:ss（后台每 5 分钟自动增量同步）」。
  - 点击「刷新用量明细」按钮快速重新聚合本地明细，毫秒级响应，不消耗全行网关拉取配额。

## 二、 管理员后台操作手册 (`/admin`)

### 1. 登录与总览
* 默认管理员账号：`admin`，默认密码：`Admin@RgOne2026`（可在系统设置中修改）。
* **全行仪表盘**：
  - 核心大盘指标：全行员工总数、已申领 API Key 数量、全行累计消耗 Token 数、算力网关连通状态。
  - **部门用量排行表**：按部门汇总消耗 Token 总量、请求频次与接入员工数，辅助算力分配。
  - **网关控制与全局同步**：提供受单例互斥锁保护的「手动拉取日志」与「测试网关连通性」功能。并发触发时自动拦截并提示「全行日志增量同步正在进行中，请勿重复触发」。

### 2. 员工底表管理
* **单条维护**：支持手动录入新增员工（8 位工号、姓名、部门）。
* **联动停用与复职**：
  - 停用员工立即阻断登录、读取与重置，并联动禁用网关 Token；若网关故障，列表将展示「网关吊销待重试」状态，并提供「重试吊销网关 Key」操作按钮。
  - 显式点击复职时，系统联动恢复其网关 Token。
* **批量导入保护**：支持 Excel (`.xlsx`) 与 CSV 模版增量导入。仅更新员工资料，**严格保留已有的停用状态**，严禁批量导入误复职。
* **删除防孤儿**：删除员工前严格联动吊销网关 Token，若网关调用失败中止删除，杜绝孤儿 Token。

### 3. API Key 管理
* 检索所有已派发的员工 Key，查看累计消耗与最后活跃时间。
* **严格启停运维**：一键启用或禁用员工 Key，仅在网关确认成功后更新本地状态。
* **强制重置**：支持为员工强制重置 Key，具有可恢复状态机支持。

### 4. 安装包与资料管理
* 上传最新客户端安装包与使用手册，系统自动计算并记录 SHA-256 校验和。
* 勾选「设为首页主推安装包」，前端首页将自动挂载该版本供全行员工一键下载。空库默认不推荐占位包。

### 5. 案例文章管理
* 内置 Markdown 编辑器与离线净化过滤器，支持拖拽上传本地图片并自动转换相对路径，过滤危险脚本与伪协议。
* 管理文章发布状态与首页置顶推荐。

### 6. 系统与网关配置
* 可视化修改 `new-api` 服务地址、User ID、系统访问令牌。
* 配置行内小秘书即时消息推送 API 端点与来源标识（支持显式测试模式切换）。
* 提供「测试网关连通性」按钮，毫秒级诊断凭据与网络状态。
